# Rugved — Portfolio

A cinematic, scroll-driven portfolio built with React, TypeScript, Vite, Three.js and React Three Fiber.

## Experience
ENTER → WALK → DISCOVER → SEE THE WORK → APPROACH THE STADIUM → REVEAL THE WORLD

Tennis is used as a quiet narrative device inside an architectural, editorial visual system.

## Run
```bash
npm install
npm run dev
npm run build
```

Edit final bio, projects and links in `src/data/portfolio.ts`.

## Deployment
A GitHub Pages workflow is included at `.github/workflows/deploy.yml`. Pushes to `main` build and publish the Vite `dist` directory.
